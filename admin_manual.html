배드민턴 대진표 관리자 설명서

대회관리자가 명단 등록부터 경기 종료까지 운영하는 방법입니다.

빠른 순서 로그인 모드 선택 선수 명단 대진 관리 현장 운영 공개 설정 문제 해결

대회 당일 빠른 운영 순서

  1. 관리자 계정으로 로그인하고 연결된 대회를 확인합니다.
  2. 대진비공개 상태에서 운영모드 또는 대회모드를 선택합니다.
  3. 선수 명단과 출석 상태를 확인하고 경기 수, 코트 수 등을 설정합니다.
  4. 대진생성을 누른 뒤 중복점검과 대진 순서를 검토합니다.
  5. 준비가 끝나면 대진공개로 전환합니다.
  6. 다음게임과 게임중을 표시하고, 경기 종료 후 승패 또는 완료를 입력합니다.
  7. 태블릿을 공동으로 볼 때는 입력잠금을 켜 오입력을 막습니다.

1. 로그인과 대회 선택

  1. 발급받은 관리자 아이디와 비밀번호로 로그인합니다.
  2. 대회관리자는 자신의 계정에 연결된 진행 중 대회만 사용할 수 있습니다.
  3. 대회가 자동으로 열리지 않으면 대회 목록에서 선택해 데이터를 불러옵니다.
  4. 상단의 접속 아이디와 대회명을 확인한 뒤 작업을 시작합니다.

사용기간이 지난 계정은 로그인할 수 없습니다. 기간 연장은 슈퍼관리자에게 요청하세요.

2. 운영모드와 대회모드

운영모드

선수가 시간차를 두고 출석하고, 진행 중에 대진을 계속 추가할 때 사용합니다.

  • 선수별 출석/제외 상태를 사용합니다.
  • 기존 경기 뒤에 추가 대진을 생성할 수 있습니다.
  • 늦참자 배려모드는 기존 경기 수를 목표 경기 수에서 차감합니다.
  • 전체인원 균일모드는 새로 생성되는 경기 수를 출석 선수에게 동일하게 보장합니다.
  • 게임중 선수 포함 여부를 선택할 수 있습니다.

대회모드

참가자가 확정된 정모, 청백전 또는 하루 대회를 한 번에 생성할 때 사용합니다.

  • 1인경기수와 코트 수를 기준으로 전체 대진을 생성합니다.
  • 청백전모드에서는 같은 팀끼리 파트너를 만들고 상대 팀과 경기합니다.
  • 4배수 대타적용을 켜면 필요한 대타를 자동 생성합니다.
  • 운영모드의 출석/제외 기능은 사용하지 않습니다.

대진 상단의 “운영모드 생성대진/대회모드 생성대진” 표시와 현재 설정 모드가 다르면 대진 편집을 피하고, 원래 모드로 돌아가 작업하세요.

3. 선수 명단과 설정

명단 입력

  • 선수 이름은 띄어쓰기, 줄바꿈 또는 쉼표로 구분해 붙여넣을 수 있습니다.
  • 명단 아래의 선수/대타/총 인원 수를 확인합니다.
  • 명단숨기기는 이름 입력 영역만 접습니다. 명단전체삭제는 선수와 관련 데이터를 지울 수 있으므로 확인창을 꼭 읽으세요.

주요 설정

항목설명
1인경기수선수 한 명에게 배정할 목표 경기 수입니다.
코트 수한 라운드에서 동시에 진행할 경기 수입니다.
랜덤시드같은 명단과 설정에서 조합을 바꾸고 싶을 때 값을 변경합니다.
탐색강도파트너와 4인 조합의 중복을 줄이기 위한 탐색량입니다. 보통은 균형을 사용합니다.
이벤트경기수전체 대진 중 이벤트 경기로 무작위 지정할 수입니다.
이벤트 금액이벤트 경기 패배 수에 곱해 선수별 벌금을 계산합니다.

청백전

  • 청백전모드를 켜고 선수별 청팀/백팀을 지정합니다.
  • 팀 인원이 불균형하면 안내창에 따라 한 명을 반대 팀으로 이동해 비율을 맞춥니다.
  • 선수 제목 옆의 작은 초기화 기능은 청/백 배정만 초기화합니다.

4. 대진 생성과 수정

  • 대진생성: 현재 모드와 설정에 맞춰 대진을 만듭니다. 기존 대진이 있으면 팝업에서 보존 범위를 선택합니다.
  • 대진삭제: 전체 대진과 결과를 삭제합니다.
  • 미완료만삭제: 승패, 완료, 게임중으로 확정되지 않은 대진만 삭제합니다.
  • 결과초기화: 대진은 유지하고 승패, 완료, 게임중, 다음게임 등의 결과 상태를 초기화합니다.
  • 수동추가: A팀과 B팀 선수 네 명을 지정해 마지막에 한 경기를 추가합니다.
  • 순서 변경: 행 왼쪽 손잡이를 잡고 원하는 위치로 드래그합니다.
  • 선수 교체: 미진행 경기의 선수 이름을 눌러 검색 후 교체합니다. 완료 또는 게임중 경기는 교체할 수 없습니다.
  • E 표시: 미진행 경기의 이벤트 여부를 추가하거나 해제합니다.

시작시간과 종료예상은 생성된 경기 수, 코트 수, 경기당 15분을 기준으로 자동 계산됩니다. 대진 추가·삭제 시에도 다시 계산됩니다.

5. 경기 당일 결과 운영

표시사용 방법
A승/B승 또는 청승/백승승리 팀을 선택합니다. 선택하면 해당 경기의 다음게임 표시는 해제됩니다.
완료승패 집계 없이 경기만 끝난 경우 사용합니다. 청백전 대회모드에서는 혼동 방지를 위해 표시되지 않을 수 있습니다.
게임중현재 코트에서 진행 중인 경기입니다. 투입가능 판단과 추가 대진 생성에 반영됩니다.
다음게임바로 다음에 들어갈 경기를 사용자 화면에 알려줍니다. 완료된 경기는 선택할 수 없습니다.
가네 명 모두 현재 다른 게임에 투입되지 않아 바로 경기 가능한 대진입니다.
E이벤트 경기입니다. 이벤트 패배 수와 벌금은 선수별이력에 집계됩니다.

확정 결과 수정

승패 또는 완료를 입력한 행은 오입력 방지를 위해 잠깁니다. 수정이 필요하면 행 오른쪽의 수정 아이콘을 먼저 누른 뒤 결과를 변경하세요.

입력잠금

태블릿을 여러 사람이 볼 때 상단 입력잠금을 누르면 관리 설정, 결과 입력, 선수 교체, 순서 변경과 삭제가 막힙니다. 다시 작업할 때는 잠금해제를 누릅니다.

6. 사용자에게 대진 공개하기

  1. 명단과 대진을 준비하는 동안 상단 버튼을 대진비공개 상태로 둡니다.
  2. 대진 검토가 끝나면 버튼을 눌러 대진공개로 전환합니다.
  3. 사용자는 전용 주소에서 대회 비밀번호를 입력해 대진표, 선수별이력, 순위를 확인합니다.
  4. 사용자 화면은 처음 접속할 때와 약 5분 간격으로 서버 데이터를 새로 불러옵니다. 급한 변경은 새로고침 아이콘을 안내하세요.

서버 즉시 저장이 켜져 있어도 중요한 변경 후에는 상단의 서버 저장 상태와 마지막 업데이트 시간을 확인하는 것이 안전합니다.

7. 자주 확인할 문제

  • 대진이 사용자에게 안 보임: 대진공개 상태인지, 올바른 대회로 로그인했는지 확인합니다.
  • 대진 생성이 안 됨: 운영모드는 출석 선수가 최소 4명인지, 제외 상태와 게임중 포함 설정을 확인합니다.
  • 투입가능 “가”가 없음: 각 대진의 네 명 중 한 명이라도 현재 게임중이면 표시되지 않습니다.
  • 결과를 수정할 수 없음: 확정된 행 오른쪽 수정 아이콘을 먼저 누릅니다. 전체 화면이 잠겼다면 입력잠금을 해제합니다.
  • 이름을 바꿀 수 없음: 완료 또는 게임중 경기의 선수는 교체할 수 없습니다.
  • 종료예상이 맞지 않음: 코트 수와 시작시간을 확인한 뒤 대진을 추가·삭제하면 자동 재계산됩니다.
  • 대진 순서가 안 움직임: 선수 이름이 아니라 행 맨 왼쪽의 손잡이를 잡고 드래그합니다.
